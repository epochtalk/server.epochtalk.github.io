    EpochtalkServerWeb.Controllers.UserJSON (epochtalk_server v0.1.0)

    Renders and formats User data, in JSON format for frontend

    Summary

    Functions

    data(map)

    Renders whatever data it is passed when template not found. Data pass through for rendering misc responses (ex: {found: true} or {success: true})

    find(map)

    Renders formatted user JSON for find

    register_with_verify(map)

    Renders formatted JSON response for registration confirmation.

    user(map)

    Renders formatted user JSON. Takes in a User with all associations preloaded and outputs formatted user json used for auth. Masks all user's roles to generate correct permissions set.
