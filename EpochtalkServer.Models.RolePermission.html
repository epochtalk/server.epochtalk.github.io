    modify_by_role(attrs)

    @spec modify_by_role(role :: map()) :: {:ok, :success}

    For admin api use.

    Updates the modified value of RolePermissions for a Role and updates the Role's permissions and priority restrictions

    If a permission is not included in new_permissions, it will be set to false. new_permissions may be an empty list - in which case, all permissions will be set to false.

    Any permissions in new_permissions which are not valid will be ignored.
